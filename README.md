## Что такое HBMax?

Это попытка перенести и переосмыслить легендарный технический мод HBM на современную версию Minecraft. Я хочу сохранить всю глубину и сложность оригинала, но при этом:

- Адаптировать код под новую версию игры
- Улучшить производительность
- Сделать графику и анимации более современными

## Цели проекта

1. **Полноценный порт** контента HBM с версии 1.12.2
2. **Заимствование идей** из самых ранних версий мода (для сохранения атмосферы)
3. **Современная графика** — все 3D модели и анимации сделаны через **GeckoLib** (вместо устаревшего OBJ-формата)
4. **Максимальная производительность** за счёт нативных оптимизаций
